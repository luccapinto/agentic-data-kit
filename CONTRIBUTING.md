# Contributing to the Agentic Data Kit

> This kit works out of the box. If you want to extend it, here's how — and, just as
> importantly, when *not* to.

---

## The Golden Rule

**Only author in `.agent/`.** Everything under `.github/`, `.claude/`, `.opencode/`, `.cursor/`,
and the root `AGENTS.md` is generated by `scripts/sync_agents.py` and will be overwritten.

```bash
# After editing anything in .agent/, regenerate every tool (needs PyYAML: pip install pyyaml):
python3 scripts/sync_agents.py

# Fail if generated folders are stale (this is what CI runs):
python3 scripts/sync_agents.py --check
```

CI (`.github/workflows/sync-check.yml`) runs `--check` on every push and pull request, so commit
the regenerated folders together with your `.agent/` change. `npm prepack` also runs the sync
before publishing.

---

## Before you add anything: the agent-survival rule

Less is more. Extra agents and verbose instructions cost the model attention. **Default to a
skill.** An agent is justified only if it imposes something the model cannot impose on itself:

1. **Restricted tools** in its frontmatter (e.g. a read-only reviewer).
2. **Independent review** — fresh context, no access to the author's reasoning.
3. **A different model.**
4. **An automatic trigger.**

If none applies, write a **skill** (narrow knowledge, a format, a checklist, a script) or a
**workflow** (a repeatable procedure the user invokes) — or nothing, when the model already
does it well ("write clean code", "use CTEs"). Capture only *domain- or org-specific* context.

If a request fails these tests, the right answer is to **not** add the artifact.

## How to add something

1. **Create** the file under the right `.agent/` subfolder:
   - Agent → `.agent/agents/<name>.md`
   - Skill → `.agent/skills/<name>/SKILL.md` (+ optional `scripts/`, `references/`)
   - Workflow → `.agent/workflows/<name>.md`
   - Global rule → `.agent/rules/rules.md`
2. **Sync** → `python3 scripts/sync_agents.py`
3. **Test** → `npm test` (Python `unittest` in `tests/`; fixture PBIP at `tests/fixtures/SalesSample/`).
   Scripts under `.agent/skills/*/scripts/` are Python 3.9+, standard library only, and support
   `--format text|json` with exit codes 0 (ok) / 1 (errors found) / 2 (usage or tool failure).
4. **Commit** the `.agent/` change and the regenerated folders together.

## Conventions

**Agents** (`.agent/agents/<name>.md`) — rare, lean, and defined by what they restrict:

```yaml
---
name: my-reviewer           # lowercase-hyphenated
description: One sharp sentence on what it does + trigger keywords.
tools: Read, Grep, Glob     # the restriction that justifies the agent
model: inherit
---
```
Body = identity (1–2 lines) → checklist/rules → output format. No handoffs to other agents.
Claude tool names are mapped for Copilot automatically (Read→read, Grep/Glob→search,
Edit/Write→edit, Bash→execute).

**Skills** — `SKILL.md` with `name` + third-person `description` (with trigger words)
frontmatter. Keep the body under ~500 lines; move long material to `references/` or `templates/`.

**Workflows** — `description` frontmatter; concise, numbered steps.

**Language** — everything in this repository (code, identifiers, docs, instructions) is
**English only**; the assistant replies in the user's language at runtime.

## Folder structure

```
.agent/            ← SOURCE OF TRUTH (edit here)
├── agents/        ← independent reviewer(s)
├── skills/        ← on-demand knowledge modules, scripts, references
├── workflows/     ← slash-command procedures
└── rules/         ← global rules (rules.md)

.github/  .claude/  .opencode/  .cursor/  AGENTS.md   ← GENERATED (do not edit)
```
